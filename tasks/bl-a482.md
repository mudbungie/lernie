PRINCIPLES.
- *Single source of truth* — the point of the change: `LERNIE_HOME` mutation had **two** homes (a guarded `with_lernie_home` in `src/cmd/tests/mod.rs` and a raw `set_var`/`remove_var` pair in `src/e2e/bundle_replay_cli.rs`), and the second silently defeated the first. There is now exactly one mutator, `crate::test_support::with_lernie_home`, so the process-global var has one authoritative writer.
- *Minimalism / subtraction* — no new abstraction, no new flag, no new test harness: an existing helper moved one module up into the module that already existed for cross-module in-process test support, and two call sites adopted it. Net +61/-48 across 4 files.
- *If it can't be tested, it mustn't be built* — the fix restores `cargo test --lib` at default parallelism as a trustworthy signal, which is the precondition for that principle holding at all; the gate's `--test-threads=1` had been masking the gap.
- *A special case is usually a missing reframe* — the earlier state treated `prime`/`new` as the special tests needing env isolation. The reframe: **every** in-process reader of the harness-root env needs it, so the guard belongs at the mutation, not at a chosen subset of callers.
