The roster paints an entry whose address is this box's own listener as a duplicate section, and the window has no way to remove an entry: the only remedy is deleting a directory by hand. A settings page lists every channel this box holds (its name here, its name on its host, the addresses it dials, where its files are, what it last said) and removes an entry behind a second click. The roster's last row, always painted, opens the page. Removal is local: it deletes this box's key and leaf for that entry; the server-side registration is the server operator's to remove. This box's own server is listed and cannot be removed here, because it is not an entry.
