## Why
No live model call has ever been made — every shipped claim rides mocked-wire tests (httpmock SSE), which is exactly how the fake worker default model id claude-sonnet-4-7 shipped unnoticed (bl-3157). ARCH documents a live 'lernie prompt' as the required smoke test after 'lernie new' (landing with bl-3157); this ball makes that runnable as one command and runs it for real.

## Deliverable
A 'make smoke' target: scaffold a throwaway workspace with 'lernie new', run one live 'lernie prompt' against the real Anthropic provider (bz, shipped defaults: worker role, claude-sonnet-5), and machine-check the outcome from observable state — exit 0, a committed transcript entry on the agent ref, a step record — never the agent's own claim. Deliberately NOT part of 'make check' or the close gate: it needs credentials and spends money; severable by design. Prefer zero new Rust (Makefile + existing verbs + shell assertions); any new source code carries the usual 100% coverage.
Document in README (how to run, what it proves, that it requires a configured bz credential).

## Acceptance
'make smoke' run once for real, output recorded in this ball before close.

### KEY FINDING (a real trap this smoke exists to catch)
An auth-FAILED run STILL creates the agent branch AND a step record whose response.json terminates in a clean '{"type":"end"}' — the failure rides an '{"type":"error"}' event ahead of it. So branch-exists / step-exists / terminal-end are necessary but NOT sufficient; a naive smoke would green a broken wire. The teeth: exit 0 AND no error event AND an assistant content_delta.
