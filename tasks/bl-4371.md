Round-1 daily lane. lernie 0.1.30 (main 4eaadcc) against yog 0.0.38 (main c7916da1), litany 0.0.10.

`lernie help` names one way to begin a conversation:

    lernie start <workspace> <goal>     begin a conversation — two acts, one word

and its page says the two acts are `prepare` then `prompt`. The `prepare` it fires is the BARE rung. yog's boundary carries three:

    /prepare | /prepare dir <path> | /prepare ball [--new <title…> [--body <text…>]]

so the rung STORIES S2 is entirely about — "the composer grows one optional affordance: a work target (a directory). Submitting with a path appends the §3.3 target preamble verbatim and sets driver cwd to the path" — is reachable from no word this seat spells. `lernie help start` does not mention that a target exists.

It is not decoration. Same model, same box, same minute, one goal each, the only difference being the rung:

BARE (what `lernie start` fires). Goal named the directory in prose. The agent's `bash` obeyed the prose while `apply_patch` wrote into the agent worktree; it thrashed, dispatched three compactors, spent 4,060,308 tokens and left a 0-byte REPORT.md in the worktree with nothing in the project.

PATH rung, reached only by hand:

    lernie ask '{"op":"prepare","workspace":"proj","payload":{"rung":"path","dir":"<repo>"}}'
    -> {"kind":"prepared","ok":true,"prepared":{"binding":"<repo>","goal":"Working directory: <repo>\nDo all work there, by absolute path. Do not rely on the current directory.",...}}
    lernie ask '{"op":"prompt","prepared":{…that object…},"goal":"…"}'

Eight steps, about a minute, no children, a good changelog written to the project root.

`ask` is not a workaround here in the way the help says it is ("This is not a fallback: it is the surface"), because the second envelope has to carry the FIRST one's whole reply object back verbatim — the thing `start`'s own page says is a local precisely because "a nested object is not a word an operator types". Every daily user therefore takes the rung that loses.

Expected: `lernie start <workspace> <goal> [<dir>]`, or a flag. The ball rung wants the same treatment; `assign`/`release`/`close` exist for balls but nothing composes `prepare ball`.

Severity p1: it is the difference between the harness working and not working on the first real goal anyone gives it, and the CLI is the whole product until the window is somebody's daily seat.
