## Scope (§9, v0.9–v0.10)
"Experiments are config diffs, measurable against a task suite" (§1 Testability). Three deliverables.

## Shipped by this epic (bl-8094)
1. **Bundle/replay (§9.2)** — `lernie bundle <workspace> <agent> <out-dir>` writes one git bundle of the `<agent>` subtree (branch + `<agent>-*` hyphen-descendants, all ancestry reached) plus `steps/<id>*` and `inbox/<id>*` slices; `lernie replay <archive>` reconstructs a scratch workspace under `LERNIE_HOME`/replays/<primary-id>/ (fetch all branches, materialize the primary worktree, restore slices) and prints the path for the ordinary frontend. Code: `src/archive/`; verbs wired thin in `src/bin/lernie.rs`; tests in `src/archive/tests.rs` + `tests/bundle_replay_cli.rs`.
2. **Task suite (v0.9, §9.1)** — 50 tasks under `tests/suite/` (one YAML file per failure category), machine-checkable `check` scripts (shell, exit 0 = pass), ≥10 tasks per §9.1 category via secondary tags, format in `tests/suite/README.md`, well-formedness enforced by `tests/suite.rs`.
