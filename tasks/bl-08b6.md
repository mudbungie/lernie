`crate::ui::roster` carries a sentence written for exactly this box:

    /// What a box with no channel at all says. It is a fact about provisioning
    /// and the operator reading it is the operator who would fix it, so it
    /// names the act rather than reporting an absence.
    pub const NO_CHANNEL: &str = "no channel provisioned — material arrives by hand";

and paints it under `if model.roster.is_empty()`. **On a real box the roster is
never empty.** `crate::seat::channels` answers a chunk for this box's own flat
slot whether or not anything is provisioned there — which is right, and is what
`lernie entries` prints as `(this box's own engine) / nothing provisioned at
…`. So the guard is false on the very box the constant was written for, and the
sentence paints only in a unit test.

What the operator gets instead, driven headless with a data root holding
nothing at all: the channels pane paints its heading, then the section header
`(this box's own engine)`, then a separator, then nothing. A dead pane. `Tab`
finds no control in it. The window's other three panes say what they are
waiting for — *pick a workspace*, *pick a conversation*, *pick a workspace to
say anything or begin anything* — and the one pane that is the whole of what a
first run has says nothing.

**A channel that failed paints the same dead section.** With entries whose
material is present but whose engine cannot be reached — one addressing a port
nothing listens on, one carrying an anchor that did not sign the engine's
certificate — the roster paints each entry's name, a separator, and an empty
body. The wrong-anchor one produces no sentence anywhere in the window at all.
That half is bl-e620's subject (the failure belongs on the row, not in the
shell-wide bar); this ball is the pane's own empty state, which is missing even
when nothing failed.

**The reframe, rather than moving the guard.** The pane has no sentence for an
empty SECTION, only for an empty roster — and an empty roster is unreachable.
Every section is either a list of walls or a reason there is none, and the
reason is already computed one layer down: `crate::channel` knows whether the
slot is unprovisioned, half-provisioned (and which file is missing), hollow, or
unreachable, and `lernie entries` prints all four as sentences today. The
window has the same facts and paints a blank.

Found by driving the window headless (X server, screenshots read back) over
scratch data roots.
