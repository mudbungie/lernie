Gesture: launch the seat on a live engine (X11, egui-winit 0.30), press Ctrl+X with or without the prompt focused. Expected: the switcher overlay (DESIGN §4.42 item 7). Observed: nothing; no frame changes. Cause: egui-winit's on_keyboard_input maps command+X to egui::Event::Cut and returns before pushing egui::Event::Key, and keys::handle matches only Event::Key{key: X, modifiers.command}. The switcher tests synthesize the Key event, so they pass while the real window never sees one. Why it matters: with nothing aimed there is no prompt field (bl-2cb0), so Ctrl+X is the only way into any conversation; a first-time operator is stranded on the seat panel, which advertises the chord.
