Filed from yog bl-a09f (carried out of yog bl-ebbd's optional sub-claim #4). The 0.0.3 write path refuses conflict-markered summaries (`merge::decline` via `content_conflicts` before `git add -A`); the read path still composes any tree's bytes verbatim.

## Verified absent in 0.0.3

`src/prompt/dispatch/assembler/body.rs` is the whole of body composition (`compose` → `walk` → `select` → `fit` → `render`). `select` reads each matched file and stores bytes verbatim:

    let bytes = std::fs::read(worktree.join(file)).map_err(Error::Io)?;
    out.push(Entry { path: file.clone(), content: String::from_utf8_lossy(&bytes).into_owned() });

No content predicate exists anywhere in the module — the only rejection is an I/O error. Repo-wide, `<<<<<<<` outside tests appears only in compaction-merge prose and `decline::content_conflicts` (git index stages) — never at assembly.

## Why it matters after the write-path fix

Any tree already carrying markers — written by 0.0.2, by an operator hand-edit, or by a `write_summary` payload that merely contains the literal strings — is still composed into every subsequent model call verbatim. ARCH §2.7 promises corrupted context 'can never happen'; this guard is what makes that promise defence-in-depth rather than load-bearing on the write path alone. Concrete prior instance: `agents/20260728T080619Z-3b14deaf:summary/001.md` in yog workspace deceit-muscular carried nine marker lines and was live at the root branch tip for days.

## Ask

Make `assembler::body::select` (or `compose`) refuse a composed entry whose content carries a line beginning `<<<<<<< `, `=======` or `>>>>>>> `, as a hard `Error` naming the path — the same refuse-loudly discipline `merge::decline` applies on the write side.

## Open design point (decide here, not pre-decided)

Scope of the refusal: every composed file, or only `summary/**`? The originating ask covered only `summary/**`, but the reasoning (context that is not what it claims to be) is not summary-specific. Counter-consideration: a skill's asset legitimately documenting merge conflicts would be refused under the wide rule — the same 'don't hold the branch hostage to a stray asset' argument that keeps non-UTF-8 composition lossy rather than fatal. Attack both before committing.
