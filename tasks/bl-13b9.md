Seen on the first offscreen run of 0.1.71: a box whose own engine listens at an address that a held-elsewhere workspace channel also names paints two engine rows on the seat panel with the same walls and conversations, and the rule's 'N waiting' and 'N engines' sum them twice. The channel directory is the operator's and may legitimately name the same engine twice (a workspace enrolled before the box became an engine). The seat should fold channels by address when it counts and when it paints the seat panel — one engine, every name it is held under beside it — and the switcher should list it once. Gesture: open the window with a workspace channel whose address equals the box's own wire address; expected one engine row and one count; observed two rows, doubled counts.
