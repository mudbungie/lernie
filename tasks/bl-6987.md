USER DIRECTIVE (Mark, 2026-07-26, verbatim intent): make the tests not flake under CPU load, and do not paper over issues by degrading critical workflows — fix them. That rules out: CI/gate retries, widened wall-clock tolerances, #[ignore]s, weakened assertions, and any 'rerun when quieter' advice as a fix.

THE CLASS: any test whose pass/fail depends on the scheduler honoring a wall-clock assumption — a timed hold vs a timed budget, a sleep racing a poll, a deadline computed from Instant::now(). Under load (16-core box at load 30-50 from parallel agent gates, or a 2-core CI runner on warm caches) these assumptions break and gates go red on unrelated changes.

THE PROVEN FIX PATTERN (bl-7a3f, on main): make the contested resource observable instead of timed (holder releases only after the spawner demonstrably retried), and/or make the budget a per-request injected parameter so tests inject margins no scheduling stretch can defeat. Production constants unchanged.

KNOWN MEMBERS, for scope discipline:
- bl-6f1b (CI tarpaulin ptrace segfault, bash-tool tests) — OWNED by agent Fathom, do not touch; coordinate via ball bodies if your audit reaches the same files.
- bl-9c06 (cmd::tests::verbs config_* parallel flake) — OWNED by agent Tiller, same.
- bl-edf6 (ETXTBSY envelope is wall-clock; README rule says attempt count) — UNCLAIMED, IN YOUR SCOPE: claim and deliver it as part of this sweep (its body carries the decided direction).

DELIVERABLE: (1) an audit — enumerate every test/production seam with a wall-clock assumption (grep Duration::from_millis/sleep/Instant::now/timeout across src/ and tests/, then judge each); record the census in this ball's body, including the ones judged safe and why. (2) Fixes for every unsafe member not owned by a sibling ball, using the bl-7a3f pattern. (3) Determinism evidence: the touched tests pass N consecutive runs under synthetic load (the bl-9300 verification used 40 CPU spinners, 30/30 passes — match that bar). README's determinism rule ('a retry budget is a count of attempts, never a wall-clock deadline') is the invariant; conform code to it, not vice versa.
