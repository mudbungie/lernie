Round 1, devadmin lane. Provisioning a foot on a second machine, which in this lane is a container and in general is a server reached over ssh.

    $ lernie enroll ops box1 foot
    box1 — foot at <lan-ip>:7743
    <a 145-column QR block, 39 lines of half-block glyphs>
    not written down anywhere — scan it now, or enroll again

That is the entire output. There is no text form of the material and no flag
that asks for one. `lernie help enroll` describes the act but offers nothing
else.

For a phone this is exactly right — REMOTE 8.4 is written for a camera. For a
FOOT it is the wrong channel for the one case feet exist to serve: a box with
no screen and no camera. The operator is holding a terminal, and the material
they need to put in a file is on their screen as a picture.

And the failure is terminal, not merely awkward. `/enroll` shreds the key
engine-side before answering — correctly — and refuses a second enrolment
under the same name, so the moment the QR scrolls, that name is burnt: the
certificate is registered, the key is gone, and the only remedy the refusal
offers is `FORCE=1`, a CA rotation that distrusts every leaf already carried
anywhere. One `lernie enroll ops box1 foot` on a headless box costs you the
name.

WORKAROUND, and it is what the lane used: the underlying gesture answers the
whole material as JSON, and `lernie ask` reaches it.

    $ lernie ask '{"op":"enroll","workspace":"ops","name":"box2","grade":"foot"}'
    {"address":"...","ca":"-----BEGIN CERTIFICATE-----...","cert":"...",
     "grade":"foot","key":"-----BEGIN ...","kind":"enrolled","name":"box2",
     "ok":true}

    jq -r .ca   > wire/workspaces/<ws>/ca.pem
    jq -r .cert > wire/workspaces/<ws>/client.pem
    jq -r .key  > wire/workspaces/<ws>/client.key
    jq -r .address | tr -d "\n" > wire/workspaces/<ws>/address

That worked first try and the foot came up. So the seat is DISCARDING the
answer it already has and rendering a picture of it.

EXPECTED: the typed verb writes the material where a person can use it. The
shapes worth considering, in the order this lane would rank them:
- `lernie enroll <ws> <name> <grade> --into <dir>` writes the four files
  directly, which is the whole of what an operator then does by hand anyway;
- `--json` prints the envelope;
- at minimum, the QR renderer says the JSON door exists, in the line under it,
  where it currently says the material is not written down anywhere.

Severity p2: the act is reachable through `lernie ask`, so the lane continued;
but the documented verb is unusable for the component whose whole purpose is a
box you are not sitting at, and using it once costs a name and a rotation.
