`lernie` 0.0.0 is reserved on crates.io (name placeholder, published 2026-07-14).

Two gaps make an accidental or incomplete publish possible:

1. `crates/lernie-ui-egui/Cargo.toml` has no `publish` key, so it defaults to publishable. A `cargo publish` run from that directory would push it to crates.io. Set `publish = false`.
2. Root `Cargo.toml` has no `repository` field. crates.io shows no source link without it. Set `repository = "https://github.com/mudbungie/lernie"`.

Out of scope (decided with user 2026-07-14): the root version stays `0.1.0` in this task. The first real crates.io release will be `0.0.1`, so the version bump is a separate call the user will make at publish time.
