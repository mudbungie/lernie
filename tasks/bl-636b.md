BRAZEN_PIN at Makefile:33):

  * new `install-bz`  - guards non-empty pin, then compares `bz --version` last token to

    `cargo install brazen --version "=<pin>" --locked`.

    `@$(MAKE) --no-print-directory install-bz`. .PHONY updated. Header comment reworded

    crates.io-pinned bz is left alone when it already matches").

.github/workflows/ci.yml - three steps inserted between "Install cargo-tarpaulin" and
"make ci" (no version number anywhere in the YAML):
  1. name: Resolve the pinned brazen version   id: brazen
     run: echo "pin=$(make --no-print-directory brazen-pin)" >> "$GITHUB_OUTPUT"
  2. name: Cache the brazen adapter binary
     uses: actions/cache@v5   path: ~/.cargo/bin/bz
     key: ${{ runner.os }}-bz-${{ steps.brazen.outputs.pin }}

     version guard (src/prompt/resolve.rs check_bz_version, ARCH 4.4). Only the binary is
     cached; registry/git caches are the pre-existing step above.
  3. name: Install the provider adapter (bz)   run: make install-bz   (no-ops on cache hit)
