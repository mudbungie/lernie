Follow-up to bl-35e2 (which retired the models table structurally going forward; the operator's 2026-07-27 ruling also asked for the file's policy values to be 'ripped out of history').

A main-branch history rewrite is DESTRUCTIVE and must not be run ad hoc:
- it force-pushes a public branch with merge history (release-plz PRs), breaking every clone, every bl work worktree under $XDG_STATE_HOME/balls, and any CI checkout;
- published crates.io tarballs (lernie 0.0.1-0.0.3) contain install/models.yaml forever — a rebase retracts nothing from distribution; that needs a separate yank/republish decision;
- yog pins lernie by exact version, so a republish moves that pin.

There are no credentials in the file — model ids, capability lists, context windows, provider names only — so this is architectural hygiene, not incident response.

DO NOT execute without BOTH:
1. an operator-scheduled quiet window: no open release PR, no live parallel worktrees, all agents idle;
2. the operator's explicit go-ahead in this ball, including the yank/republish decision.

See bl-35e2 for the structural fix that landed first.
