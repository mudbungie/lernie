`lernie start` with the wrong number of arguments answers:

    lernie: `lernie start` takes a workspace and a goal — usage:              lernie start <workspace> <goal>

Fourteen literal spaces between `usage:` and the usage. It is one string in
`crate::cli::run`'s `["start", ..]` arm, and the run reads as a wrapping
artifact from when the line was laid out over two rows in the source.

Every other refusal in the binary spells this the same way with one space:

    lernie: `lernie conversations` takes 1 argument(s) and got 0 — usage: lernie conversations <workspace>

so the odd one out is `start` alone, and it is one of the two verbs an operator
is most likely to get wrong (it is the only verb that is two acts, and the
only one whose second argument is prose that must be quoted).

Reachable four ways: no arguments, one, three, or more. `lernie start` and
`lernie start <ws>` are the ordinary ones.

Found by walking every verb's argv arity refusals against the 0.1.0 binary.
