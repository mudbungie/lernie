Gesture: type '/find ünïcødé 日本語 🦀' and Enter.
Expected: the needle reads back as typed in the box, the field and the 'looked for' line.
Observed: Latin with diacritics paints; each CJK character and the emoji paint as an empty box in all three places. The search itself crosses and answers. Not a crash; an operator writing in a CJK language cannot read their own draft.

## Assessment (FixB, assess only — no font shipped; operator's decision)

**Why it is tofu.** The seat ships egui 0.30's `default_fonts` and sets no FontDefinitions of its own. Those are four files: Ubuntu-Light 362 KB, Hack 309 KB, NotoEmoji-Regular 419 KB, emoji-icon-font 318 KB (~1.4 MB in all). NotoEmoji-Regular's cmap holds 887 code points: it has U+1F600 😀, U+1F44D 👍, U+2764 ❤ and lacks U+1F980 🦀 (Unicode 8 and later) and every CJK ideograph, kana and hangul syllable. egui 0.36's default fonts are byte-identical (same 887 code points), so an egui upgrade changes nothing.

**Measured on a stock Linux desktop (this class of box):** release binary 13.1 MB. System fonts present: NotoSansCJK-Regular.ttc 19.5 MB (five regional faces in one collection), DroidSansFallbackFull.ttf 4.0 MB (CJK plus some other scripts, one face), NotoColorEmoji.ttf 11.0 MB — colour bitmaps (CBDT), which epaint 0.30's glyph rasterizer cannot draw at all, so it is no answer for emoji at any size.

**Options, with cost:**

| Option | Shipped bytes | Other cost | Covers |
|---|---|---|---|
| A. Load a system fallback at startup: probe a short fixed list of well-known paths with std::fs (Linux Noto CJK .ttc / Droid fallback; macOS PingFang/Hiragino .ttc; Windows msyh.ttc / YuGoth) and push it last in both families (FontData's `index` selects a face inside a .ttc) | 0 | No new crate. RAM: the font's bytes stay resident (4–20 MB) and are parsed at startup. A box with none of the paths is still tofu. A test needs a font file to load: either probe-only tests, or a fixture font in the tree (an asset) | CJK where the OS has it; emoji no better |
| B. Embed one CJK face (include_bytes) | full single regional face ~8–16 MB (estimate, not measured here); a subset to common characters ~2–4 MB (estimate) | An asset under Cargo.toml's approval rule, an OFL licence row in deny.toml, the leak-scan allowlist of tracked binaries stops being empty (binary font), crate package size grows by the same | CJK on every box, deterministic, testable |
| C. Add a newer monochrome Noto Emoji as fallback | ~1–2 MB (estimate) | Same asset/licence/allowlist cost as B | Post-2015 emoji in one colour; colour emoji impossible on epaint 0.30 |
| D. An operator-named font file (env or config) | 0 | A new config surface — a flag where a default would do | Whatever the operator points at |
| E. Leave it, and say so in the README | 0 | CJK operators cannot read their own drafts | — |

**Recommendation:** A, alone. It costs nothing in the binary, adds no dependency and no asset, and the operators who type CJK are exactly the ones whose OS already carries a CJK face. Pair it with a probe-only test (the probe list is a pure function; the push into FontDefinitions is testable with whatever font egui already has). B and C wait for a reason to make the binary heavier; D is a flag where A is the default.
