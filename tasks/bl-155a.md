OPERATOR INSTRUCTION (2026-09-02): full CI/CD — seat boxes (the desktop GUI machines) track releases unattended. The engine's retired binary-era reconciler was the wrong shape for a container unit but is the RIGHT shape for a seat binary: there is no unit to restart and no turn to kill — 'cargo install lernie --locked' against the crates.io sparse index, and the next window launch runs the new build.

Shape: scripts/deploy/ (or this repo's equivalent — check the tree; if none exists, found it on yog's scripts/deploy pattern): a user timer + script seated over ssh by 'make deploy-seat HOST=<ssh-host>' — HOST an argument, never committed (leak rules + severability, same as yog's seat.sh). The script: read the newest live version from the sparse index, compare to the installed binary's version, install with explicit --version --locked --force on difference. A yanked release resolves to the previous live version, so yank remains the rollback lever (the engine reconciler proved this live). No restart of anything; if the window is open it finishes its session on the old build.

Also state, in the script header, the protocol-skew fact: a seat that updates ahead of its engine may speak a newer PROTOCOL and be refused at the hello until the engine box catches up (engines reconcile hourly from ghcr) — the refusal is the designed behavior, not a defect to code around.

Constraints: no new dependencies; the reconcile script's decision logic testable with fake curl/cargo shims per this repo's test discipline; leak rules on everything committed (no hosts, no accounts, no addresses).
