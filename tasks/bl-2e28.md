Deferred from bl-8801 (packaging hygiene). The evaluation runner `crates/agent-eval` (ARCH §9.3) is complete and fully covered, but the far side of its agent seam is empty: `--agent <cmd>` names an external harness-driver program and NO SUCH PROGRAM EXISTS. Until one is written, no evaluation run (experiment × suite × N) can be performed and the §9.1 suite data (50 tasks) has never been measured against a live model — so the v0.10 success criterion is not met (ARCH §9.3 "Not yet runnable end to end", §11 v0.10 shipped shape).

bl-8801 removed the phantom `lernie-eval-agent` default rather than leaving a spawn failure per task: `--agent` is now required, `make eval` requires AGENT=, and the driver contract is documented in README "Run the suite".

The contract a driver must honour, per run:
- prompt: argv[1]
- LERNIE_HOME (env): the isolated harness root for this run
- LERNIE_EXPERIMENT (env): path to the experiment workflow.yaml
- LERNIE_EVAL_REPORT (env): path of a file the driver MAY write with exactly two lines — workspace path, then agent id — which is what `lernie bundle` needs to archive a failing run (§9.2). Absent or malformed only makes the run un-bundleable; never an error.
- cwd: the working directory shared with the task setup and check
- the driver exit code is IGNORED; pass/fail is the task check alone (exit 0 the sole pass signal, §9.1)

Shape of the work: the driver is `lernie new` a workspace + `lernie prompt` the task prompt under the experiment workflow, then report the workspace path and root agent id. Decide first whether it is a binary in this repo (a second [[bin]] or a third workspace crate, publish=false) or a script under scripts/ — an integration is an external binary (docs/PRINCIPLES.md), so it must not become a lernie verb. Done when `make eval CONFIG=baseline SUITE=tests/suite RUNS=5 AGENT=<it>` produces a real pass@1/pass@5 report, and the honesty caveats added by bl-8801 (ARCH §9.3, §11 v0.10, README "Run the suite", tests/suite.rs, tests/suite/README.md) are retired in the same change.
